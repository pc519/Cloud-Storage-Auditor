# ☁️ Cloud Storage & Database Auditor (Firebase & AWS S3)

A passive cloud security auditing tool built with Python to check whether a company's Firebase Realtime Databases or AWS S3 storage buckets are publicly accessible due to misconfigured permissions, producing a clear HTML security report.

### ✨ Features
- Firebase Database Check: Tests public read permissions on standard and default Firebase RTDB endpoints.
- AWS S3 Bucket Audit: Checks common storage, assets, and backup bucket naming patterns for public exposure.
- Client-Ready HTML Report: Categorizes findings clearly (Publicly Accessible, Protected, or Not Found).
